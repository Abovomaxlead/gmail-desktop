# Topbar in plaats van de zijbalk — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** De accountnavigatie verhuist van een vaste kolom van 72px links naar een horizontale balk van 40px bovenaan, die tegelijk de titelbalk van het venster is.

**Architecture:** Het venster wordt `titleBarStyle: 'hidden'` met een `titleBarOverlay`, zodat Electron de échte vensterknoppen bovenop onze balk tekent en wij alleen ruimte en kleuren leveren. De plaatsing van de webview zit al op één plek (`contentBounds`) en verandert van een x-offset naar een y-offset. De zijbalk-JSX verhuist uit `page.tsx` naar drie eigen componenten; `page.tsx` houdt de staat en de IPC.

**Tech Stack:** Electron 31, TypeScript, Next.js (renderer), Tailwind, vitest.

**Spec:** `docs/superpowers/specs/2026-08-03-topbar-design.md`

## Global Constraints

- Nederlands in commentaar en gebruikersteksten; Engelse identifiers. Commentaar legt *waarom* uit, niet *wat*.
- Pure logica in een eigen module met tests; opmaak wordt niet getest.
- Tests draaien onder vitest zonder DOM en zonder Electron. Geen jsdom.
- `TOPBAR_HEIGHT = 40`, op één plek gedefinieerd (`electron/layout.ts`) en van daaruit gebruikt door de bounds-berekening, de hoogte van `titleBarOverlay` en de CSS van de balk.
- Er blijft altijd minstens **60px** sleepruimte in de balk over.
- Elke knop in de balk krijgt `-webkit-app-region: no-drag`.
- `titleBarOverlay` en `titleBarStyle: 'hidden'` bestaan alleen op Windows en macOS. Op Linux (waar onder WSL ontwikkeld wordt) blijft het native frame staan en mag `setTitleBarOverlay` niet worden aangeroepen.
- Elk uitklapmenu in de balk moet `setMenuOverlay(true)` sturen, anders klapt het open achter de Gmail-view.
- Na elke taak: `npx tsc --noEmit`, `npx tsc --noEmit -p renderer/tsconfig.json` en `npm test` schoon.
- `npm run build` werkt niet zolang de dev-server draait (EPERM op `renderer/.next/trace`). Gebruik `npm run build:main`.
- **Volgorde:** begin niet voordat de fixronde van de push-branch is gecommit — die bewerkt `renderer/app/page.tsx` en `electron/ipc.ts`.

```ts
// De hoogte van de topbar, op één plek. Drie dingen lezen deze waarde: de
// bounds-berekening hieronder, de hoogte van titleBarOverlay (zodat de echte
// vensterknoppen precies in onze balk vallen) en de CSS van de balk zelf. Lopen
// die uiteen, dan hangen de knoppen half buiten de balk.
export const TOPBAR_HEIGHT = 40;

// No margin around the active Gmail/Calendar view: the webview sits flush
// against the topbar so there is no dark frame from the renderer background.
export const CONTENT_MARGIN = 0;

// `scale` is de zoomfactor van de renderer (2 in Rene-modus): de vaste 40px
// balk tekent dan scale× hoger, dus de content-view moet daaronder beginnen.
export function contentBounds(
  win: { width: number; height: number },
  scale = 1,
): {
  x: number;
  y: number;
  width: number;
  height: number;
} {
  const topbar = Math.round(TOPBAR_HEIGHT * scale);
  return {
    x: CONTENT_MARGIN,
    y: topbar + CONTENT_MARGIN,
    width: Math.max(0, win.width - CONTENT_MARGIN * 2),
    height: Math.max(0, win.height - topbar - CONTENT_MARGIN * 2),
  };
}
```

`electron/titlebar.ts`:

```ts
import { TOPBAR_HEIGHT } from './layout';

// Electron tekent de echte vensterknoppen als overlay bovenop onze topbar. Wij
// leveren alleen de maten en de kleuren aan. Die kleuren moeten meelopen met het
// thema, want anders staan de knoppen donker-op-donker zodra je omschakelt.
export interface OverlayOptions {
  color: string;
  symbolColor: string;
  height: number;
}

// Dezelfde waarden als de achtergrond van de balk in de renderer: Tailwind's
// neutral-100 en neutral-950. Wijken ze af, dan zie je een naad tussen de balk
// en het gebied waar de knoppen staan.
const LIGHT = { color: '#f5f5f5', symbolColor: '#404040' };
const DARK = { color: '#0a0a0a', symbolColor: '#d4d4d4' };

// Het thema wordt in de renderer toegepast (een class op <html>), dus main kan
// het niet uit de DOM lezen en rekent het hier zelf uit.
export function isDarkTheme(
  choice: 'system' | 'light' | 'dark',
  systemDark: boolean,
): boolean {
  return choice === 'dark' || (choice === 'system' && systemDark);
}

export function overlayOptions(
  choice: 'system' | 'light' | 'dark',
  systemDark: boolean,
  reneMode: boolean,
): OverlayOptions {
  const colors = isDarkTheme(choice, systemDark) ? DARK : LIGHT;
  // Rene-modus zoomt de renderer naar 200%, dus de balk tekent twee keer zo
  // hoog. De overlay rekent in vensterpixels en zoomt niet mee.
  return { ...colors, height: reneMode ? TOPBAR_HEIGHT * 2 : TOPBAR_HEIGHT };
}

// titleBarStyle: 'hidden' en titleBarOverlay bestaan alleen op Windows en macOS.
// Op Linux houden we het native frame: het is geen doelplatform, maar er wordt
// wel onder WSL ontwikkeld en de app mag daar niet omvallen.
export function supportsOverlay(platform: string): boolean {
  return platform === 'win32' || platform === 'darwin';
}
```

```ts
// De overlay met de echte vensterknoppen moet meelopen met het thema en met de
// zoom van Rene-modus. Anders staan de knoppen donker-op-donker na een
// themawissel, of 40px hoog in een balk van 80px.
function applyTitleBarOverlay(): void {
  if (!prefs || !mainWindow || mainWindow.isDestroyed()) return;
  if (!supportsOverlay(process.platform)) return;
  const p = prefs.getAll();
  mainWindow.setTitleBarOverlay(
    overlayOptions(p.theme, nativeTheme.shouldUseDarkColors, p.reneMode),
  );
}
```

```ts
import { APP_SURFACES, type Surface } from '../lib/surfaces';

// Wat er in het rechtsklikmenu van een tabblad komt. In de zijbalk stonden deze
// knoppen zichtbaar naast elk account; in de balk zou dat te vol worden.
//
// De renderer kent de AccountRef niet — main stuurt alleen `kind` en
// `hasCalendar` mee — dus dit werkt op die twee velden. De regels zijn dezelfde
// die de zijbalk inline gebruikte.
export interface TabMenuAccount {
  kind: 'authuser' | 'delegated';
  hasCalendar: boolean;
}

export function tabMenuSurfaces(p: TabMenuAccount): Surface[] {
  const out: Surface[] = [];
  // Agenda alleen als er een is: bij een gedelegeerd postvak hangt dat af van
  // wat Google's accountwisselaar heeft prijsgegeven.
  if (p.hasCalendar) out.push('calendar');
  // Drive, Docs en de rest bestaan alleen voor je eigen accounts; voor een
  // gedelegeerd postvak gooit het bouwen van die url's een fout.
  if (p.kind === 'authuser') out.push(...APP_SURFACES);
  // `mail` staat er bewust niet in: daarvoor klik je het tabblad zelf aan.
  return out;
}
```

```tsx
  label,
  x,
  y,
  activeSurface,
  onPick,
  onClose,

  label: string;
  x: number;
  y: number;
  activeSurface: Surface | null;

  onClose(): void;

      {/* Wegklik-vlak; vangt ook de rechtsklik zodat een tweede rechtsklik het
```
